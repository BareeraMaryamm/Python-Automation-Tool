# 🤖 4-in-1 Python Automation Tool

A powerful Flask-based automation dashboard that integrates multiple external APIs to fetch real-time data in one place.

### ✨ Features
- 💰 **Crypto Tracker** - Live prices of Bitcoin, Ethereum, Solana, Cardano (CoinGecko API)
- 🌤️ **Weather Update** - Live Lahore weather (Open-Meteo API - No Key Required)
- 💵 **Currency Converter** - USD rates for PKR, EUR, GBP, INR (ExchangeRate-API)
- 📰 **Tech News** - Latest 4 tech articles (HackerNews Algolia API)
- 💾 **File Handling** - Auto-saves all data to `all_data.json`
- 🎨 **Modern UI** - Glassmorphism cards with filter buttons

### 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **APIs:** REST APIs with `requests` library
- **Concepts Used:** API Integration, Exception Handling, File Handling, Flask Routing

### 🚀 How to Run
pip install flask requests
python automation_app.py
# Open http://127.0.0.1:5000
